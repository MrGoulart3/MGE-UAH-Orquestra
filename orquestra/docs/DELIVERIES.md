# File delivery and central links

`deliver_file file... -d "description" --space sample-alpha` replaces the personal delivery-command name. `ORCHESTRA_PROJECTS` controls project detection; `ENTREGAS_DIR` controls the private output root (default `~/.local/share/mge-deliveries`). Copies use private permissions; `--mover` moves instead. Same space/name increments a version under an index lock. `--mudou`, repeated `--pergunta`, `--substituir` and optional Office PDF/contact-sheet previews retain the event schema in `indice.jsonl`. Preview dependencies are optional (`soffice`, `pdftoppm`, Pillow); `--sem-previa` disables conversion. Invalid space identifiers cannot escape the delivery directory.

The public Portal currently uses workspace inbox/outbox directories rather than this deployment's central delivery index. To expose a space's delivered files, configure that workspace's `files.workspaces.<label>.outbox` to the corresponding `ENTREGAS_DIR/<space>` directory. The Portal lists the actual files and supports manual downloaded/not-downloaded marks. Central-index version descriptions and questions are retained for index consumers but are not a public-Portal UI feature in this update.

`central_add --titulo "Example tool" --url https://example.org/tool --space sample-alpha --desc "Description" --tipo ferramenta` adds/updates a private link catalog; `--listar` lists and `--arquivar URL-or-id` archives. Set `ORCHESTRA_CENTRAL` (default `~/.config/mge-agentportal/central.json`). It does not publish anything. The public Portal does not yet render this catalog; it is available to an integrator through the JSON file. Do not point it at a credential file.
