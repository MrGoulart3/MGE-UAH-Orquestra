# Session restart and context handoff

`contexto_spaces --status` reads context bars; `--noite` restarts idle sessions above `CTX_LIMITE` (default 40%) during 21:00–07:00, serially, at most three per night. It discovers agents dynamically. The configured coordinator is protected from self-restart. The daytime preparation flow records `reinicio/<pane>.pronto` only after the agent has saved rules, continuity and a local commit.

`reiniciar_space <pane> --barato` creates a handoff before exiting the old session. `--cancelar` persists a veto, `--liberar` removes it. A per-pane lock prevents concurrent close/restart. Cancellation and readiness are checked again immediately before exit. A fresh session must expose a different session ID before receiving its startup prompt. `--forcar` skips readiness, not a recorded cancellation. These commands do not stop computation jobs; background-exit confirmation retains running work.

`passagem_space <pane> --sem-ia` extracts transcript text, edited files, job commands and commits locally. Without `--sem-ia`, an optional bounded Haiku summary adds decisions, pending work and pitfalls, with no tools or MCP servers. Failures are recorded as missing summary, not invented content. It stores five recent handoffs and archives older ones; it never deletes raw research data. `custo_sessoes [since_ISO] [--space filter]` estimates relative token-weight shares, deduplicating message/request IDs: input 1, cache write 1.25, cache read .1, output 5. These are estimates, not billing totals.

`fechar_space <pane>` requires successful immediate delivery of a save-and-commit request; busy/unreadable input returns failure so a caller can retry. It then waits for idle, requests `/exit` and verifies closure. `--direto` skips preparation and is for an explicitly prepared session. `acordar_space <workspace>` checks local capacity, chooses the first pane only if every pane is agent-free, tries `--continue`, then falls back to a clean session and continuity. No close command closes the workspace itself.
