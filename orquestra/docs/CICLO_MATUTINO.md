# Morning cycle

`ciclo --ancora 05:00`, `ciclo --tol 1`, `ciclo --status`, `ciclo --plano`, `ciclo --liberar` configure the anchor, tolerance, inspection and temporary release. Configuration is stored in `ORCHESTRA_STATE/ciclo.conf`. Local time governs the schedule. An active window lasts five hours; the controller protects the anchor from a new window starting too late. In the last night window the default 80% cap closes the door until morning. `ciclo.limite_noite` can hold `percent|expiry_epoch` for a temporary limit. Morning is capped at 30% for the entire window (`CYCLE_MORNING_CAP`).

`ciclo_controle` holds a lock and delegates to `ciclo_core.mjs`. It blocks at reset minus ten minutes, projects future windows without model calls, retries the anchor at +0/+2/+5 minutes and records confirmation. The one intentional model operation is `ancorar_janela`: disabled until `CICLO_ENABLE_PING=1`, with configurable `CLAUDE_BIN` and `CICLO_MODEL`. Failure is logged and notified; a successful process with an unavailable meter is marked unverified. The current controller opens the door after exhausted retries, so monitor its failure notification.

Install `bin/ciclo_porta_hook` manually as a Claude UserPromptSubmit command hook, preserving existing hooks. It reads JSON stdin and emits a blocking decision when `PORTA_FECHADA` exists. `CICLO_ANCORA=1`, an unexpired `CICLO_LIBERADO`, direct operator messages and configured `porta_excecoes` (`directory|expiry_epoch`) are exceptions. A hook is essential: a notification alone does not block credits.

`ancora_reserva` is a Bash fallback, active from anchor +3 to +90 minutes. Schedule independently through cron and a user systemd timer. All mechanisms still share the machine/network. Set an expiry long enough to cover +90 minutes for a manual release. `acordar_manha` notifies selected existing agents once per day; `acordar_manha.conf` holds `ESPACOS=workspace_ids`, and `ORCHESTRA_EXCLUDE` is a comma-separated exclusion list. The default selects all nonexcluded agents. It does not start closed workspaces.

Suggested schedules (install manually with explicit ORCHESTRA_CONFIG): controller every five minutes; reserve at minutes 2,7,… and independently 4,9,…; `ciclo_controle --teste` at 21:00; `--plano` at 21:30. The test inspects hooks, executable availability, meter and schedules without model calls. Do not install schedules until fake-adapter tests pass.
